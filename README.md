## O que este projeto faz

Este projeto implementa um agente para navegar em um pomar de manga gerado deterministically a partir de uma matricula. Ele compara estrategias de busca, heuristicas, busca local, regras especialistas e calculos de Bayes.

## Como rodar

Python 3.11 ou superior.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python src/main.py <matricula>
```

O comando principal sera implementado nas proximas etapas e gerara os arquivos da pasta `resultados/`.
